## Intent

The "product promo" cut of the e2a launch (v1, the three-pillar tour), a companion
to the 30s narrative teaser in `../e2a-launch`. Position e2a as **communication /
email infrastructure for agents** — send transactional mail from any app, give an
agent a real two-way inbox, and keep people in control.

**Register: "play mode" — upbeat and energetic.** Faster pacing, springier entrances,
quicker reveals, a little more colour pop (amber, plus the brand's spectral/info hues
as playful accents), count-ups and snappy UI motion. Still the warm editorial e2a
brand (cream / canopy / amber, Fraunces + Inter + JetBrains Mono) — just livelier than
the calm cinematic teaser. Not cyberpunk, not loud-for-loud's-sake.

## Customizations

- Reuse the e2a design system (`frame.md`) and real staged fonts from the teaser.
- Real default addresses `agent@agents.e2a.dev` (shared domain, not `@e2a.dev` root).
- Exact install command `claude plugin install e2a@e2a`; exact logo / URL / tagline as vector.
- Motion: energetic — quick springy entrances, sequenced snappy reveals, a count-up
  where a number fits; keep it seek-safe (no repeat/yoyo), no exit tweens except final.
